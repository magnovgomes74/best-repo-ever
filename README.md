# best-repo-ever

Repositório de estudos e práticas de controle de versão com Git e GitHub criado durante a trilha do Salesforce Trailhead.

## Comandos Aprendidos

- `git status` - Verifica o estado das alterações.
- `git add` - Adiciona arquivos para a Staging Area.
- `git commit` - Salva o snapshot das alterações.
